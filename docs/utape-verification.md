# Late tape on vacated U wires: independent review

Named limit: **I2.model's zero-caller row narrowed from the reference's gate**. The layout and the approved row change are separate commits. The layout alone intentionally fails the reference zero-caller row; the follow-on row is a control confirming the domain narrowing, not a correctness test of that caller.

The width lemma L6 was reviewed from a separate proof that is not in this repository. Its hypotheses are an odd prime q and 1 <= x < q at the pass entry (q,x). The multiplier maps its original x=0 to 1 first. L6 bounds logical U by the scheduled width at every nonterminal boundary; the terminal state is (1,0), which fits every positive tail width. It does not cover the generic V=0 caller, which leaves logical U=q.

At the first boundary after width w where the next width is w', each original U wire j >= w' that has not become tape is zero. The emitted step's U input shape is now exactly w, and its internal step gates are otherwise unchanged; later widths do not grow. The queue adds eligible high U wires only after that boundary, behind vacated V wires. The allocator does not free those U wires or lend them elsewhere before their cell use. Therefore they remain zero and untouched until used as tape. Once a wire is a cell it no longer represents that logical high U bit; no claim says its physical value stays zero after reuse.

The independent verifier observes the real generated step boundaries and every actual primitive operand. It checks every above-width U wire not yet used as a cell at every boundary, not only the selected wires. It scans each interval from that wire's first retired boundary to its first cell step, or the pass end if never lent. Controls substitute the live U0 wire in the scan and test a generic zero caller; both detect violations. Small-prime tests enumerate every nonzero x, and secp checks are directed/seeded. The general claim rests on L6, the unchanged internal step and the width-restricted register shape, not on secp sampling.

The output boundary permutes U and the pool together. U receives its surviving low wires plus zero wires from V's tail and the freed block positions; the remaining pool holds the coded tape. The physical input/output wire sets are equal and have no duplicates. The recorded block retains this full output layout, so inverse application uses the mirror renaming. Independent M forward and inverse checks compare every output and scratch wire with arithmetic expected states; inverse input is prepared clean independently, not copied from a forward simulator result. Original x=0 is tested through M's remap.

The code table and cell arithmetic do not change. Streaming calls are removed; each complete block is encoded in the tail and decoded/recoded for Bezout. Measurements traverse actual calls and observe allocator peaks without changing emitted bytes. The whole peak remains at Bezout, so the saved calls improve cost without a whole-wire reduction.

For each line the layout-only model checker fails exactly pass_zero_ok on all small-prime rows. The follow-on accepted row changes that key to pass_zero_outside_domain, with all other keys and the secp row identical, and the remap control still gating.
